8.0.2 MINI localization and standard version identity — 2026-11-21

Follow upstream v8.0.2: provide separate MINI images for English plus Czech,
German, Spanish, French, Italian, Polish, Japanese, or Ukrainian. They are
not one combined multilingual BBF. Keep the previously published English-only
mini image available too. Model families already covered by 8.0.2 do not need
an older-version backport merely to duplicate this fix.

Use PROJECT_VERSION_SUFFIX=-RME. Runtime identity and public asset names use
8.0.2-RME without any additional UI/build suffix. Keep existing tags intact.

Flash savings preserve language coverage, update controls and thermal checks:
- Byte-oriented RME I/O requests fit four ARM argument registers.
- Coalesce complete download reads and durable metadata publication into
  worker jobs, retaining fflush/fsync/close and rename failure handling.
- Share exact upload READY response formatting across fresh/resumed transports.
- Use compact language-table loops instead of unrolled searches. Validate
  registration, duplicate replacement, capacity, zero-code behavior, language
  selection and provider identity against the original implementation.
- Include cleanup-authorization removal and directory preparation in worker
  dispatch, not only explicit stdio calls, before starting an RME upload.

Every localized build must have exactly its requested translation bit in
BUILDID, its compiled catalog in the resource tarball, a matching version/model
and source commit, a valid BBF signature and resource digest, and a successful
flash link. Never relabel an older or English-only image as a localized 8.0.2.

Upstream asset layout verified using the official GitHub release API:
https://github.com/prusa3d/Prusa-Firmware-Buddy/releases/tag/v8.0.2
