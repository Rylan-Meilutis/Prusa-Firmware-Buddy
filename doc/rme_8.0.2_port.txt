Published upstream 2026-11-16. Official assets cover CORE One, INDX, CORE One L,
XL, MK4/MK3.9, MK3.5, and eight MINI language pairs. Use the established 15
RME build presets for those machine families; unknown versions remain rejected.

Port strategy: merge the actual official tag into the latest maintained
RME 8.0.0 source, not merely a version-string change. This includes upstream
8.0.1 fixes as well as 8.0.2. Preserve all RME LCD/menu-transition recovery,
automatic-runout workflow terminal events, cold-park dock fan, serial Tune
focus, entry-only pellet-ejection setting/remote control, chamber-wait status,
M591 logging correction, probe readiness and bootloader safeguards.

Upstream changes to retain and verify:
- Crash detection paused during homing; MMU First Layer Calibration fallback.
- Incomplete OpenPrintTag metadata is handled without null-string failure.
- USB control/string lengths, directory entry bounds, JSON/Connect argument
  length validation, and UTF-8 null handling security fixes.
- XL manual Printer Type setting and persisted mismatch warning; MINI heater
  retraction and XL fan-test corrections from 8.0.1.

Release gates: exact upstream ancestry; clean committed source; RME GUI
regressions; upstream native parser/UTF-8/Connect tests; all supported signed
builds; per-machine version/model checks, application bounds and embedded
resource hashes; ECDSA signatures; INDX runtime heap guard; downloaded public
release bytes equal qualified artifacts. No printer flash/restart is part of
building or publishing. Hardware stability/timing remains unverified.
