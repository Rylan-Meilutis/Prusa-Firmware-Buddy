# M979: INDX automatic dock-fan cooldown

```gcode
M979 S1 C180 ; enable automatic cooling; shut off 180 seconds after latest park
M979 S0      ; disable automatic mode; restore legacy manual fan control
M979         ; passive status query
```

INDX only. `S` must be exactly 0 or 1. `C` is a whole number of seconds from
1 through 86400, permitted only with `S1`; omitting it with `S1` selects 180.
Malformed commands are rejected without changing mode. Mode is volatile,
defaults to manual at boot, and remains selected across jobs until `S0` or
reboot. Profiles requiring manual behavior after an automatic job must emit
`M979 S0`; not emitting M979 does not reset an already enabled mode.

Orca should put `M979 S1 C180` before its start G-code in the RME INDX profile.
Other machine profiles must not emit this INDX-only command.

The fan is commanded to full speed before every potentially hot physical park,
including manual park and calibration paths. Because INDX has no reliable cold
classification for an unattached nozzle, every park is treated as potentially
hot. The interval restarts on completed park and again for each newer park;
queued tool-change timestamps are not used. Failed attempts also start the
timer. Picking a nozzle does not shorten the running interval.

Cooling is serviced using the firmware millisecond clock in the Marlin service
cycle, including during blocking G-code, after completion/cancellation, and in
idle. There is no queued dwell and no dependency on print duration or host
progress. M106/M107 P6, print-finalization Off and calibration restoration are
requests routed through this policy and cannot shorten a running cooldown.
Automatic mode owns the output: full speed during cooldown, Off at expiry,
even if an earlier manual request was nonzero. Other fans are not affected.
`S0` is the explicit opt-out and immediately restores the latest manual PWM
request.

## Timer-based behavior

**Automatic shutoff is based on the configured elapsed time, with no additional
safety hold.**
`IndxHotend::stop_heating()` clears the nozzle temperature on park. The attached
nozzle thermal model does not provide parked-nozzle cooling measurements or a
validated conservative dock-cooling envelope. As requested, the firmware turns
the fan off when `C` seconds have elapsed since the latest park, even while
nozzles remain parked. This is not a claim that they are below a measured safe
temperature, and no temperature threshold or decay coefficient is invented.

Example status after the interval expires:

```text
RME_DOCK_COOLDOWN enabled=1 seconds=180 remaining=0 pending_mask=0 mode=timed pwm=0
```

`remaining` is the shutoff timer, not a nozzle temperature estimate.
`pending_mask` records tools parked during the current interval and clears
at expiry; it is not a cold-nozzle indicator.

The policy is not persisted over power loss. It does not implement print
recovery, detect manually moved nozzles, or certify physical fan airflow.
