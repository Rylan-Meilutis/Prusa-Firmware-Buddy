# M141 / M191 chamber temperature control

RME firmware accepts the standard chamber-temperature commands used by
OctoPrint and slicers:

```gcode
M141 S40 ; set a 40 C chamber target without waiting
M191 S40 ; set the target and wait for heating
M191 R40 ; set the target and wait for heating or cooling
M141 S0  ; disable chamber temperature control
```

On CORE One and CORE One L equipped with a working xBuddy Extension chamber
sensor, heating is assisted by the heatbed. The toolhead print fan circulates
warm air at a low duty cycle; CORE One L also uses its under-bed circulation
fans. The controller never lowers an independently requested bed or print-fan
setting and restores the prior values when the target is reached, cancelled,
or disabled.

The heatbed assist normally yields to an active print. A blocking `M191`
heating wait is the exception, because serial hosts commonly enter print mode
before executing start G-code. The assist is released before `M191` returns,
so the print's own bed and fan settings take over.

Cooling continues to use the existing xBuddy Extension chamber cooling and
filtration controller. The chamber target is clamped to the machine's existing
safe maximum (55 C on CORE One and 60 C on CORE One L).
